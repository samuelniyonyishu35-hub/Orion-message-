# ORION Messages
Native Android SMS/MMS client built with Kotlin and Jetpack Compose.

## Build
Push to `main` or run **Build ORION APK** in GitHub Actions. Download the APK from the workflow run's Artifacts section.

## Requirements
- Android 8.0+ (API 26+)
- SMS permissions and the Android default SMS role for full SMS handling
- Dual-SIM selection is exposed where the device/carrier supports multiple active subscriptions

## Important
This is the initial foundation release. MMS, group messaging, delivery reports, and advanced SIM/carrier behavior need device testing before being considered complete.
