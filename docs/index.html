SamSim

Messagerie SMS pour Android

Découvrez SamSim, une application de messagerie simple pour gérer vos SMS sur votre téléphone Android. Chaque utilisateur retrouve ses propres messages sur son appareil.

Télécharger SamSim pour Android

Après le téléchargement, ouvrez le fichier APK et suivez les instructions d'installation d'Android.
